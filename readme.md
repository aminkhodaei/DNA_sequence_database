This section contains viral disease genomic nucleotide sequences collected from the NCBI virus section:


This repository contains several Excel files, which contain DNA sequence data downloaded from the NCBI site, and classified based on virus type and countries.

This repository contains the dataset files used in these papers:  
[1] Amin Khodaei, Parvaneh Shams, Hadi Sharifi, Behzad Mozaffari-Tazehkand,
Identification and classification of coronavirus genomic signals based on linear predictive coding and machine learning methods,
Biomedical Signal Processing and Control, Volume 80, Part 1, 2023, 104192, https://doi.org/10.1016/j.bspc.2022.104192.

[2] Khodaei, A., Mozaffari-Tazehkand, B. & Sharifi, H. A genomic signal processing approach for identification and classification of coronavirus sequences. Soft Comput 29, 321–338 (2025). https://doi.org/10.1007/s00500-024-10377-y

[3] Khodaei, A., Eskandari, S., Sharifi, H., Mozaffari-Tazehkand, B. PRCFX-DT: a new graph-based approach for feature selection and classification of genomic sequences



## Description of Files

- **Description:** This file contains the raw data collected from the NCBI virus sections.  
- **Contents:** Each sheet is related to a specific virus or variant, and each row represents a sample Accession number.  


## How to Use

You can download the files directly and use them to reproduce the results of the paper.
